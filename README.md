# Power BI Dashboard Analytics

Tableau de bord Power BI consacré à l'analyse des données étudiantes.

## Ouvrir le rapport

Téléchargez [projetbi.pbix](projetbi.pbix), puis ouvrez-le avec Power BI Desktop. Le fichier contient le modèle de données et cinq pages : Accueil, Démographie, Absentéisme, Performance et Vue Étudiant.

Le fichier `.pbix` est une copie exacte de l'archive fournie (`projetbi.pbix.zip`) ; seule son extension a été adaptée au format Power BI Desktop.
